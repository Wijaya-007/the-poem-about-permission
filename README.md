# The unlocked shed — a poem about permission

A short poem about permission: the power to ask and to be given. The speaker stands outside an unlocked shed, cap twisted in both hands, waiting for a nod to lift a latch that never had a lock — the permission was never needed; it was only ever in their own head.

`main.ts` (Node 22, stdlib only, no network) writes the poem to `/output/entry.txt`, deterministically, every run.
